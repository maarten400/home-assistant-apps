# SimpleX Alert Bot

Experimental Home Assistant app for ARM64/Raspberry Pi 5. Runs the official SimpleX CLI and HTTP bridge in one container with a new persistent identity.

See [DOCS.md](DOCS.md) for installation, initial pairing, Zabbix, Alertmanager, multi-project routing, security and troubleshooting.

This initial version is not tested on physical Home Assistant hardware. Enable the watchdog after successful first setup. Build failures or API differences should be reported with redacted app logs, never tokens or database files.
